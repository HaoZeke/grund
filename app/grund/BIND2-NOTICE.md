The PxWeb v1 request rules used when GRUND_BIND2 is set follow the behaviour
described by janbrus/pxwebapi-skills, which is published under the MIT
licence. Those rules are: omit a variable that carries elimination when the
total is wanted, use the top filter for the newest periods, and request
json-stat2. No text from that project is included in this tree.

Hagstofa serves API v1 only. A query stays within 5,000 values, 100,000
cells, and 100 calls per 10 seconds.

A difference, a share, or any other figure this program calculates is not a
published cell. The sentence says it was calculated from two named cells of
a named table. The publisher is not credited for the transformed figure.
