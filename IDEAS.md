# On site

Ranked by what each hour is likely to move on the 60-question file. The file is 30 questions in each language. English is already far ahead of Icelandic, so Icelandic wording is the first hour.

1. **Icelandic word forms in the search, not only in the refusal check.** `launavísitalan`, `gistinóttum`, `gististöðum`, and `innflytjendum` are the same words as the table titles, in another case. An hour spent making the search treat those as the dictionary form should unlock the wage index and the overnight-stay questions in Icelandic. That is most of the Icelandic miss list.

2. **Births.** "How many children were born" still lands on stillbirths or on first-born children. Prefer the live-birth total when the question does not say "first" or "stillborn". One change, and it repairs the births questions in both languages, including the ones that divide by population.

3. **Immigrants.** The municipality table and a labour-force register outrank the origin table, so the answer is 85,577 or a register count instead of 77,226. Down-rank a table that cuts by municipality when the question says Iceland and does not name a town.

4. **The wage-index point change.** The English question for August 2025 to August 2026 came back as 7.8 from a monthly change column, not 61.6 from the index levels. Tell a "by how many points" question to subtract the two index values.

5. **Two source cards.** Hard questions already fetch two tables. The page shows one card. Showing both, with both cell keys, is what a judge will look for on the two-table question. A couple of hours in the chat page.

6. **Ten questions you do not tune on.** Write them on Saturday morning, in both languages, and do not look at the score until Sunday. The 60 published questions are the ones everyone will fit. A private ten tells you whether the hour was real.

7. **Read cells from the unpacked files when the API is slow.** The track ships the tables as `data.px`. The live API is what this run used. If the hall network is bad, a reader for those files keeps the demo up. Half a day, and only worth it if the API is actually failing.

8. **The optional model on the supercomputer.** The scored path does not need a model. If the account is working, point the optional planner at the tunnel and use one question to show that a bad guess is rejected before a number is stated. An hour once the login works. A fine-tune is not worth the GPU time this weekend.

9. **Do not rebuild the embedding index first.** The misses above are wording, a birth label, and a near-duplicate table. A new index does not fix those, and it spends the hour you needed for item 1.
